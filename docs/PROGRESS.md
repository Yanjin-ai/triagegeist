### P4 + P5 results (model_structured_v1, eval = 6k held-out slice)
- **Calibration:** confidence ECE 0.0223 → **0.0119** (isotonic OVR); class-wise ECE 0.0124 → 0.0085. Reliability figure saved.
- **Uncertainty:** entropy is a strong error filter — Q4 (highest) 38% error vs Q1 0.2%. → human-review/LLM queue.
- **ESI-4 trade-off:** boosting class-4 bias lifts recall_4 0.79→0.89 with no loss to acuity-1/2 recall (small QWK cost); grid documented.
- **Fairness (bootstrap CIs):** undertriage higher for Estonian (7.4% [2.6–13.2]) & `insurance=unknown` (5.9%) vs Finnish (2.5%); **`pain_missing=1` group QWK collapses to 0.78** (and has no critical cases) — a real data-quality/equity flag.
- **Protective override (negative result, on purpose):** physiology safety net *lowers* agreement (QWK 0.93→0.895) because labels are text-determined — quantifies the risk of complaint-encoded triage.
- **Error taxonomy:** 854/864 errors off-by-one; 15 "physiology-silent severe" (e.g. *bacterial meningitis suspected*, true acuity 2, normal vitals).
- **OOD:** only the small % of test complaints unseen in train need true generalization; entropy is the operational OOD proxy.

### ⚠️ CRITICAL FINDING (reshapes strategy) — see `reports/INSIGHT_label_leakage.md`
The acuity label is a **near-deterministic function of `chief_complaint_raw`** (99.7% phrase→single acuity; 99.8% of test phrases appear verbatim in train). So:
- Text/fusion ⇒ **QWK ≈ 1.0** — the leaderboard is essentially a lookup table, **not** a measure of clinical modeling.
- **The honest, clinically meaningful model is the TEXT-BLIND structured-physiology model (QWK ≈ 0.93).** All governance (calibration/fairness/ops) runs on *that*.
- **Dual track:** `submission_fusion.csv` (~1.0) = LB formality; structured model = the judged story, led by this leakage finding.
